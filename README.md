# Proyecto G17 - HPMB01

Proyecto académico de **Herramientas de Programación Móvil – Construcción de Muebles**.

## Tecnologías

- Kotlin
- Android
- Android Views / XML
- Material Design 3
- PhotoView para ampliación de imágenes

## Estructura implementada

La Entrega 2 define una actividad principal y cinco fragmentos:

- `MainActivity`: menú lateral y navegación.
- `PerfilFragment`: información y control del tamaño del texto.
- `FotosFragment`: galería y diálogo de imagen ampliada.
- `VideosFragment`: lista y reproductor interno preparado para recibir los videos.
- `WebFragment`: navegador integrado con campo de URL.
- `BotonesFragment`: guía de uso.

## Pendientes

Las imágenes reales de muebles y los videos/tutoriales deben ser incorporados por el equipo. La estructura queda preparada para agregarlos.

> Nota: el paquete actual es `com.tunombre.creaciondemuebles`, siguiendo la estructura indicada en la entrega. Antes de una entrega final puede reemplazarse por el paquete definitivo.
